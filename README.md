# Monitor de Preços da Concorrência — Rede Amarelinha Tintas

Dashboard estático (HTML/CSS/JS autocontido) para acompanhamento de preços de lojas concorrentes,
agrupado por orçamento. Sem backend — os dados ficam embutidos no próprio HTML.

## Conteúdo
- `index.html` — o dashboard completo (abre offline, sem dependências externas).

## Concorrentes monitorados
Saci Tintas, RN Tintas, Carola Tintas, Diamante Tintas.

## Atualização
Este dashboard é gerado pela skill `precos-concorrentes` (Claude), a partir de orçamentos em PDF.
Para atualizar, substitua `index.html` pela versão mais recente gerada pela skill e faça commit.
